# Maison Élise — Luxury Nail Atelier

Landing page demonstrativa de Nail Designer, feita em HTML/CSS/JS puro e pronta para GitHub Pages.

## Publicar
1. Crie um repositório no GitHub.
2. Envie `index.html`.
3. Settings → Pages → Deploy from a branch → `main` / `/root`.
4. Salve.

## Personalizar
Troque no `index.html` o nome, WhatsApp, Instagram, cidade, preços, horários e imagens.
Os dados da agenda são demonstrativos.
